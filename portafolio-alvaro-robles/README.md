# Portafolio de Álvaro Robles

Sitio estático en HTML, CSS y JavaScript vanilla, preparado para GitHub Pages.

## Abrir localmente

Abre `index.html` directamente en el navegador. Para una vista local con servidor, desde esta carpeta ejecuta `py -m http.server 8000` y visita `http://localhost:8000`.

## Estructura

- `index.html`: página principal y contenido semántico.
- `styles.css`: diseño responsive, accesibilidad y estilos de impresión base.
- `script.js`: navegación interna por secciones.
- `cv-alvaro-robles.html`: CV provisional editable que funciona como respaldo mientras incorporas el PDF definitivo.
- `CV-Alvaro-Robles.pdf`: nombre recomendado para el CV definitivo. Colócalo en esta misma carpeta para que el botón lo descargue.

## Publicar en GitHub Pages

Sube estos archivos a un repositorio y configura GitHub Pages para servir desde la rama principal y la carpeta raíz. No requiere backend, claves ni proceso de compilación.
